================================================================================
                    CROPDEAL MICROSERVICES API REFERENCE
================================================================================
Document Version: 2.0
Architecture: Spring Boot Microservices, Spring Cloud Gateway, Eureka Server,
              Spring Cloud Config Server, RabbitMQ Event-Driven Architecture,
              MySQL per-service Databases, Resillience4j Circuit Breaker & Saga.

Base Gateway URL: http://localhost:8080 (Docker / Localhost)
Direct Microservice Ports:
  • Config Server:        8888
  • Eureka Server:        8761
  • API Gateway:          8080
  • Auth Service:         8081
  • User Service:         8082
  • Crop Service:         8083
  • Price Service:        8084
  • Order Service:        8085
  • Negotiation Service:  8086
  • Invoice Service:      8087
  • Payment Service:      8088
  • Wallet Service:       8089
  • Bidding Service:      8090
  • Delivery Service:     8091
  • Notification Service: 8092
  • Review Service:       8093
  • Chatbot Service:      8094
  • Report Service:       8095
  • Audit Service:        8096

Security & Authentication:
  • JWT Bearer Token (Authorization: Bearer <JWT_TOKEN>)
  • Public Endpoints: /api/v1/auth/**, /api/v1/crops/search, /api/v1/crops/all,
                      /api/v1/prices/mandi, /api/v1/auctions/live, /api/v1/chatbot/ask
  • Role-Based Access Control: FARMER, DEALER, DELIVERY_PARTNER, ADMIN

Standard Error Response Format:
{
  "timestamp": "2026-09-18T19:00:00",
  "status": 400,
  "error": "Bad Request",
  "message": "Specific error description",
  "path": "/api/v1/..."
}

SERVICE: AUTH SERVICE
REGISTER USER
HTTP METHOD:
POST
ENDPOINT:
/api/v1/auth/register
AUTHENTICATION:
Not Required
INPUT:
Request Headers:
Content-Type: application/json
Request JSON:
{
  "fullName": "Ramesh Kumar",
  "email": "ramesh.farmer@cropdeal.com",
  "password": "Password@123",
  "mobileNumber": "9876543210",
  "role": "FARMER"
}
REQUIRED FIELDS:
fullName: String
email: String
password: String
mobileNumber: String
role: String (Enum: FARMER, DEALER, DELIVERY_PARTNER, ADMIN)
OPTIONAL FIELDS:
None
FIELD DATA TYPES & ENUMS:
fullName: String
email: String (Valid email format)
password: String (Min 6 characters)
mobileNumber: String (10 digits)
role: Enum [FARMER, DEALER, DELIVERY_PARTNER, ADMIN]
Example Request:
POST /api/v1/auth/register
OUTPUT:
HTTP Status:
201 CREATED
Response JSON:
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "refreshToken": "7c9e6679-7425-40de-944b-e07fc1f90ae7",
  "userId": 1,
  "email": "ramesh.farmer@cropdeal.com",
  "role": "FARMER",
  "fullName": "Ramesh Kumar"
}
Response fields and data types:
token: String
refreshToken: String
userId: Long
email: String
role: String
fullName: String
ERROR RESPONSES:
400 BAD REQUEST:
{
  "timestamp": "2026-09-18T19:00:00",
  "status": 400,
  "error": "Bad Request",
  "message": "Email is already registered"
}
EXPLANATION:
Registers a new platform user (Farmer, Dealer, or Delivery Partner) and generates an initial JWT authentication token.
